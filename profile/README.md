AeroThemePlasma is an alternative shell for KDE Plasma, using a set of components under the AeroShell umbrella name. The project aims to recreate the look and feel of Windows 7 and other versions of Windows
on the Linux desktop, while adapting the style to modern KDE Plasma features where it makes sense to do so.

This is a read-only mirror of the project which can be found [here](https://gitgud.io/aeroshell/).
